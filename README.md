# Urlaub Platz Finder

## Beschreibung
Diese Anwendung ist dazu gedacht, Reisenden zu helfen, die idealen Urlaubsziele zu finden. Benutzer können ihre Reisepräferenzen eingeben, einschließlich Budget, Reisedauer und gewünschten Aktivitäten. Die Anwendung durchstöbert dann verschiedene Reiseangebote und zeigt passende Optionen an.

## Funktionen
- Benutzerregistrierung und -anmeldung
- Such- und Filterfunktionen für Reiseziele
- Vergleich von Angeboten aus verschiedenen Reiseanbietern
- Bewertungen und Empfehlungen von anderen Nutzern
- Möglichkeit, persönliche Favoriten zu speichern

## Technologien
- Frontend: React.js
- Backend: Node.js mit Express
- Datenbank: MongoDB
- Authentifizierung: JWT

## Installation
1. Repository klonen
   ```bash
   git clone https://github.com/username/urlaub-platz-finder.git
   ```
2. Abhängigkeiten installieren
   ```bash
   npm install
   ```
3. Server starten
   ```bash
   npm start
   ```
